PROXY / PREFETCH SERVICE — TECHNICAL DESCRIPTION (NOT LEGAL ADVICE)

This server (server.py / server-go) is infrastructure for caching and delivering static assets and preload APIs for a gaming web application. It is not a gambling operator, payment processor, or game-authority.

WHAT IT DOES
- Serves compressed static files (br / gzip) from disk caches
- Provides /api/prefetch and /api/prefetch/chunk to list and split asset batches for warm-up
- Delivers the frontend lobby (app/) at / and the game build (game/) at /game
- Applies CORS and Cache-Control headers for browser clients

WHAT IT DOES NOT DO
- Does not process wagers, deposits, withdrawals, or user accounts
- Does not influence game outcomes, RNG, payouts, or betting rules
- Does not host betting markets or offer gambling services directly
- Cache/preload is purely delivery optimization; it has no effect on game mechanics
